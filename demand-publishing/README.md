# 领榜首页与发布需求原型

公开预览：https://17611185912l-cmd.github.io/lingbang-index/demand-publishing/

本目录为自包含 HTML 原型，图片、CSS、脚本均内嵌，无需构建。

- 普通发布、首页老师卡片指定发布，所有必填项预填。
- 开启收费：非会员单次 9.9 元，会员免费；支持购买会员、邀请获得会员或券。
- 关闭收费：所有人直接发布，表单按钮为“发布需求”，不显示费用行。
- 原型演示面板可切换身份、收费、邀请奖励及支付结果；刷新重置。
- 月度会员 19.9 元，年度会员 99.9 元；有效邀请每人得 2 元券，累计每 10 人再得 1 个月会员。
- 演示假设：每次发布可用一张 2 元券，实付 7.9 元。券抵发布费规则待确认。

仅用于流程演示；无真实支付、需求发布、用户邀请或消息发送。
